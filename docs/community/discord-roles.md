# Discord roles

Roles in the VS14 Discord server. Source of truth for the @-role
system; sync to the live Discord when the server is set up
(tracked in vs-2l2).

## @Member (default)

Every joined account, no manual assignment. Full participation on
public channels; no admin powers. Most of the community lives at
this level.

## @Verified

Players who've connected their Discord account to their Wizden hub
account. Optional but recommended — gates participation in some
channels (role applications, event signups). Verification flow is
set up as part of vs-2l2.

## @Admin

Members of the admin team. There is currently one admin (the
maintainer); the role is forward-looking for when the team grows.
See [`admin/expectations.md`](./admin/expectations.md) for what
admins do.

Requirements:

- 2FA enabled on Discord (self-attested)
- Acknowledged the admin docs (see [`admin/onboarding-checklist.md`](./admin/onboarding-checklist.md))

## @Bot

Community bots — the watchdog status bot, future event-bridge bot
(vs-bsx), future calendar bot. Bots are clearly named and operate
within their declared scope.
