# VS14 server description

The longer description shown in the SS14 launcher's server-info
panel when a player clicks into VS14. Source of truth for the
`game.desc` cvar in
[`instances/vacation-station/config.toml.example`](../../instances/vacation-station/config.toml.example).

Sits between the [hostname tagline](./positioning.md) (4 words,
shown in the server-list line) and the [about page](./about.md)
(full long-form). Adapted from positioning to fit the launcher
panel's size — about 50–60 words.

## Current description

> Vacation Station 14 is a casual SS14 hangout server focused on
> collaboration and creativity. Light roleplay, chosen-family
> co-op vibe, and a unique fork curated from many sibling
> stations. The community lives across both Discord and the
> game — drop in, share the space, take care of it together.
> SFW, 16+, hub-listed via the Wizards' Den.
