# VS14 MOTD

Message-of-the-day broadcast to each player when they join the
lobby. Source of truth for the `chat.motd` cvar in
[`instances/vacation-station/config.toml.example`](../../instances/vacation-station/config.toml.example).
Admins can override at runtime via the `set-motd` command;
edits to this file become the new default after a server
restart.

## Current MOTD

> Welcome to Vacation Station 14 — a casual SS14 server focused
> on collaboration and creativity. Have fun, take care of the
> space, and drop in any time.
